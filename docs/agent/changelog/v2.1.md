## v2.1.6 | 2026-11-28 | Pre-release | Fix AVIO Cursor Desync, Tail Probe Stall Hedge, Concurrency Cap & Terminal Error Teardown
- **Scope**: `KernelRust` (`net/avio_bridge`, `c_api`), `DonbyKernelC` (`donby_kernel.h`), `DonbyNetwork` (`TurboStreamByteHandle*`), `DonbyCore` (`PlaybackPolicies`, `AppUpdatePolicies`), `DonbyApp` (`Player/PlayerView+PlaybackEngine`), `Tests/DonbyCoreTests`, `build_app.sh`, `scripts/package_dmg.sh`, `docs/agent`
- **Root Cause / Goal**: Fix playback stall and fatal health-check failure when resuming large 4K MKV streams (e.g., 31.79 GiB MKV with a 1.53 MiB tail `Cues` element) caused by Rust/Swift `DKStreamBridge` AVIO cursor desync corrupting FFmpeg EBML `Cues` parsing, compounded by unhedged zero-byte tail probe stalls, `inFlight > cap` concurrency saturation (`9..12` on `cap=4`), missing `stopNativeKernel()` teardown on terminal errors, and tight steady-state stall budgets during deferred remote initial seeks.
- **Changes**:
  - `KernelRust/src/net/avio_bridge.rs` (`DKStreamBridge::avio_read`): Made Rust `cursor_offset` the authoritative single source of truth by updating `cursor_offset.store(cur + n, Ordering::Release)` whenever `miss_read_cb` returns `n > 0`; added regression test `miss_read_advances_rust_cursor_without_swift_set_cursor`.
  - `Sources/DonbyNetwork/TurboStreamByteHandle.swift` & `TurboStreamByteHandle+Completion.swift` (`tryCopyDirectTailLocked`, `tryFromAttempt`, `read`, `readDirectTailRange`): Synced `dk_net_bridge_set_cursor` on both direct-tail and partial-buffer return paths and aligned `nativeCursor != cursorOffset` on `read` entry; detected stalled direct tail fetches (`received == 0` past adaptive cold threshold or `> 2.5s` byte idle) and allowed up to one alternate-lane hedge per offset (`directHedgedOffsets`) under `dynamicConcurrencyCap + 1` with lock-free `reportLaneStall`.
  - `Sources/DonbyNetwork/TurboStreamByteHandle+Scheduler.swift` (`stepBulkPrefetchSchedule`): Counted all `activeAttempts.count` (bulk + `trimmedEarly` + `isRescue` + direct tail) when gating bulk lookahead, enforced `effectiveCap + 1` burst cap on rescues, and proactively cancelled finished or `> 3.0s` stalled `trimmedEarly` tasks (with range-safe chunk cleanup).
  - `KernelRust/src/c_api.rs` & `Sources/DonbyKernelC/include/donby_kernel.h` (`dk_player_is_seeking`): Exposed `bool dk_player_is_seeking(const DKPlayer* player)`.
  - `Sources/DonbyCore/PlaybackPolicies.swift`, `Sources/DonbyApp/Player/PlayerView+PlaybackEngine.swift`, `Tests/DonbyCoreTests/DonbyCoreTests.swift`: Added bounded `seekStallBudgetSeconds` (`20.0s`) and `isSeeking: Bool = false` to `PlaybackHealthPolicy.evaluate(...)` (wired to `dk_player_is_seeking(handle)`), called `stopNativeKernel()` before surfacing terminal errors on both `DK_STATE_ERROR` (with immediate `return` preventing post-stop `handle` dereference) and `PlaybackHealth` `.fail`, and added unit tests covering 12s steady-state and 20s bounded seek recovery/termination.
- **Invariants & Pitfalls**:
  - `DKStreamBridge::avio_read` MUST always advance `cursor_offset` to `cur + n` on `miss_read_cb` `n > 0` so Rust Fast Path 1/2 can never replay stale offsets; never fall through after `stopNativeKernel()` inside `handleProgressTimerTick()` to avoid calling `dk_player_*` on a handle queued for async destroy; keep all modified source files `<= 800L`.
- **Verification**:
  - `cargo test --manifest-path KernelRust/Cargo.toml` (`14/14`), `DONBY_TEST_MUTED=1 DONBY_HOME=$(mktemp -d) ./scripts/dev.sh test` (`71/71`), `DONBY_PURE=1 ./scripts/dev.sh test` (`66/66`), `python3 scripts/check_agent_docs.py --staged` PASS; live `/Applications/Donby.app` playback verified.
