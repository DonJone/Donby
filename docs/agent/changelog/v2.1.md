# Changelog Shard: v2.1.x

## v2.1.1 | 2026-11-27 | Pre-release | Architecture 2A: Zero-Crate Rust Media Data Plane, 8-Lane BDP Scheduler & Sparse Direct-Write Store
- **Scope**: `KernelRust` (`net/{mod,slab,disk_store,disk_reconcile,avio_bridge}`, `c_api_net`, `player`, `lifecycle`, `lib`), `DonbyKernelC` (`donby_kernel.h`), `DonbyNetwork` (`TieredAssetChunkStore*`, `TurboStreamingSessionHub`, `TurboStreamByteHandle*`, `DownloadStreamingHelpers`, `DonbyDownloadManager*`), `DonbyApp` (`Player/PlayerView+PlaybackEngine`), `DonbyCore` (`AppUpdatePolicies`), `Package.swift`, `DonbyCoreTests`, `build_app.sh`, `scripts/package_dmg.sh`, `docs/agent`
- **Root Cause / Goal**: Eliminate Swift `Data` reallocation/copy churn, out-of-order `chunks/<idx>.chk` double-write amplification, the `4`-lane / `< 4.5 MB/s` HTTP/2 concurrency ceiling, and `4–6 MiB` steady-state Range TTFB sawtooth bubbles while preserving `URLSession` macOS system proxy/PAC/HTTP3 compatibility and zero Cargo dependencies ([ADR-005](../decisions/005-zero-crate-rust-media-data-plane-2a.md)).
- **Changes**:
  - **Zero-Dependency `KernelRust` Media Data Core (`KernelRust/src/net/*`, `c_api_net.rs`, `donby_kernel.h`)**: Added physical-RAM-tiered `GlobalSlabPool` (`96/160/256/384 MiB` fixed `512 KiB` pages with head/tail anchor pinning), `DKChunkStore` full APFS sparse `media.bin` POSIX `pread`/`pwrite` storage + FNV-64 `chunks.bitmap` + `SEEK_DATA`/`SEEK_HOLE` reconciliation + legacy `.chk` one-shot folding + tombstone `invalidate_for_removal()`, `DKStreamBridge` in-kernel `AVIO` fast path (`dk_player_attach_stream_bridge`), `DKDownloadAssembler`, and `PlaybackCompanionPacer`.
  - **Adaptive `4..8` Lane Hub & `8–32 MiB` BDP Range Scheduler (`TurboStreamingSessionHub.swift`, `TurboStreamByteHandle*.swift`, `TieredAssetChunkStore*.swift`, `PlayerView+PlaybackEngine.swift`)**: Expanded `TurboStreamingSessionHub` to `4` warm + `4` on-demand lanes (`maxStreamLaneCount = 8`) with `withUnsafeBytes` zero-copy partial slab ingestion, removed the `< 4.5 MB/s` H2 boost lock in favor of bitrate-vs-cushion scaling, expanded steady-state Range spans to `8 / 16 / 32 MiB` once `leadCachedChunks >= 16`, and wired `PlayerView` to `dk_player_attach_stream_bridge`.
  - **Delegate-Direct Offline Downloader & Companion Pacer (`DownloadStreamingHelpers.swift`, `DonbyDownloadManager*.swift`)**: Replaced `AsyncThrowingStream` + `Data.removeSubrange` worker buffering with `openDirectStream` + `DKDownloadAssembler` direct `SlabPage` commits, and enabled token-bucket-paced single-worker companion downloading when active playback holds `>= 64` chunks (`32 MiB`) of steady cushion.
- **Invariants & Pitfalls**:
  - Keep `KernelRust/Cargo.toml` `[dependencies]` empty (`0` crates); never invoke Swift C callbacks while holding any Rust mutex (`DKStreamBridge::partials_mtx -> DKChunkStore::meta_mtx -> GlobalSlabPool::pool_mtx`); never open `media.bin` with `O_CREAT` on read paths; keep `DONBY_PURE=1` completely free of `DonbyUHDModule`.
- **Verification**:
  - `./scripts/dev.sh test` & `DONBY_PURE=1 ./scripts/dev.sh test`: Rust kernel (`13/13`), Swift `DonbyCoreTests` (`63/63` full / `58/58` pure), and `check_agent_docs.py` (`176` owned files, `<= 800L`, `0` orphans, `0` broken links) PASS.
  - `./scripts/release_local.sh 2.1.1 --prerelease`: packaged, synced `/Applications/Donby.app` in-place, and published GitHub Pre-release `v2.1.1`.
