## f35082e | 2026-11-21 | v1.4.0 | UHD startup, HTTP/2 adaptive streaming, async L2 cache & zero-freeze seek
- **Scope**: `turbo-network`, `kernel-cpp`, `metal-renderer`, `app-player-ui`, `build-release`
- **Root Cause / Goal**: Full-stack UHD real-server audit (`/goal`) targeting cold/warm startup, rapid scrubbing, uncached 4K Remux seeks, and sustained 55 GiB playback smoothness with zero freezes/rebuffers.
- **Changes**:
  - `Sources/DonbyNetwork/TurboCacheAndDownloadEngine.swift` (`TieredAssetChunkStore`): Moved L2 disk writes (`media.bin`, `chunks/<idx>.chk`, `meta.json`) off `storeChunk()` onto serial `diskQueue` (`com.donby.chunkstore.disk`, `.utility`) with `pendingDiskChunks` read-through and 64-chunk backpressure cap; dropped `.atomic` on spill chunks; drained `diskQueue.sync {}` on flush/close/materialize/remove. Fixed `didEnsureChunksDir = false` reset whenever empty `chunks/` directory is removed during compaction/materialization.
  - `Sources/DonbyNetwork/TurboCacheAndDownloadEngine.swift` (`TurboStreamingSessionHub`, `TurboStreamByteHandle`): Added `URLSessionTaskMetrics` protocol detection + `hostProtocolMultiplexed` cache (`h2`/`h3`). Added `0.55s` seek-burst gate (`min(2, cap)`), `4`-stream steady-state `h2` cap (scaling to `5` when throughput `< 4.5 MB/s` & `leadCachedChunks < 6`), bounded Range spans (`2 -> 2 -> 4 -> 6 MiB`), EWMA TTFB-adaptive cold rescue (`max(2.2, min(4.5, smoothedResponseTTFB * 2.5))`), zero-waste unaligned seek sprint (`initialByteSkip` when `offsetInChunk >= 64 KiB` via `directSlices`), Chunk 0 (`trimmedEarly`) + final 2 EOF chunks persistence, and L1 retention (pin Chunk 0 + EOF; skip behind-cursor eviction while `memoryBytes <= 75%`).
  - `Sources/DonbyKernelC/dk_engine.cpp` (`DKPlayer`, `AudioStartingGuard`, `dk_try_start_audio_queue_if_ready`, `dk_audio_decode_worker`, `dk_player_acquire_frame`): Synchronized first video frame presentation with `audio_queue_started`; deferred `audio_queue_started = true` until after `AudioQueuePrime` + `AudioQueueStart` return `noErr` with `audio_queue_starting` atomic + `state == DK_STATE_PLAYING` recheck; serialized `AudioQueueStop`/`Reset` against `audio_queue_starting`; moved fallback AudioQueue start off CVDisplayLink (`dk_player_acquire_frame`) onto `dk_audio_decode_worker`; trimmed leading misaligned A/V samples/frames; tuned initial preroll (`rebuf == 0`) to `24000` samples (`0.50s`); moved continuous silence underrun detection above `video_queue.empty()`; redacted `Opening URL` log.
  - `Sources/DonbyMetalRenderer/DKMetalVideoView.swift`: Added `clearDisplayedFrame()` on player detach/nil and `onFirstFrameRendered` callback on `MainActor`.
  - `Sources/DonbyApp/PlayerView.swift` & `AppState.swift`: Kept loading pill until `hasRenderedFirstFrame`; added delayed (`>= 0.48s`) `"正在缓冲..."` pill; extended `isSettlingSeek` guard to `2.5s`; called `activeTurboHandle?.wakeWaitingReads()` on audio track switch; redacted `媒体流解析成功` URL log.
  - `Sources/DonbyNetwork/UHDStreamClient.swift`, `EmbyClient.swift`, `AppUpdateManager.swift`, `build_app.sh`: Extended playback/asset cache TTL `90s -> 300s`; parallelized UHD domain resolution; bumped version to `1.4.0`.
- **Invariants & Pitfalls**:
  - See [ADR-002](../decisions/002-h2-adaptive-concurrency-and-l2-cache.md): Never lock `h2` concurrency to 2 on low `leadCachedChunks`, never use fixed `1.5s` cold rescue, always reset `didEnsureChunksDir = false` when deleting `chunks/`.
  - Never call `AudioQueuePrime`/`Start` on CVDisplayLink thread.
- **Verification**:
  - Real-server UHD audit (14.31 GiB & 11.71 GiB): Warm reopen `dk_open=12ms`; Rapid Scrub Storm `firstFrame=448ms`, `0` rebufs, `maxGap=52ms`; Cached `-5s` rewind `49ms`, `+10s` forward `37ms`.
