## 1. File Inventory & Core Symbols
- `Sources/DonbyCore/DonbyStoragePaths.swift` — `DonbyStoragePaths`: Centralized path resolver supporting `DONBY_HOME` environment override (`isIsolatedHome`, `cachesDirectoryURL`, `applicationSupportDirectoryURL`, `libraryDirectoryURL`, `moviesDirectoryURL`).
- `Sources/DonbyCore/ServerCredentialStore.swift` — `ServerCredentialStore`, `ServerCredentialSecret`, `EncryptedFileVaultBackend` — stores all server `password` and `accessToken` values in a machine-bound **AES-256-GCM** encrypted `0600` file (`Application Support/Donby/credentials.vault`, key derived via `CryptoKit` HKDF-SHA256 + `IOPlatformUUID`). Eliminates macOS Login Keychain per-update password prompts on ad-hoc signed builds, automatically honors `DONBY_HOME`, performs one-time migration out of legacy plaintext `UserDefaults` and `v1.4.13–v1.4.15` Keychain entries (deleting the old Keychain item afterward), skips writes on metadata-only updates, and preserves credentials on read/write failures.
- `Sources/DonbyCore/DonbyLogger.swift` — `DonbyLogger`, `DonbyLogLevel`, `DonbyLogEntry` — in-memory ring + serial background `ioQueue` file logging (non-blocking log writes and lock-free file export). Note: `DonbyLogger` itself does NOT redact strings; callers logging URLs/tokens MUST pass them through `PlaybackDiagnosticsRedactor.redact(_:)`.
- `Sources/DonbyCore/HeroTopEdgeSynthesizer.swift` — `HeroTopEdgeSynthesizer.synthesizeWeightedStrip(topBandRGBA:width:rows:outputHeight:)` — synthesizes the 1:1 color-matched, zero-blur weighted vertical top-edge strip (`#03`) for `DetailView` pull-down overscroll using tight vertical exponential decay (`exp(-y / 1.1)`) and per-column median-anchored RGB distance outlier suppression (`1 / (1 + (dist / 0.28)^2)`), preserving crisp column boundaries with zero horizontal blur.
- `Sources/DonbyCore/SubtitleAndPlaybackPolicies.swift`
  - `SubtitleTextDecoder` — BOM check + ordered fallback (`UTF-8 -> Big5 (2563) -> GB18030 (1586) -> UTF-16LE -> UTF-16BE`) with Chinese punctuation plausibility scoring.
  - `SubtitleTextTransform` — `CFStringTransform` (`Hant-Hans` / `Hans-Hant`) preserving `{...}` ASS override tags.
  - `SubtitleHDRPeakNits` (`203 / 250 / 400`), `SubtitleStyleConfiguration` (`schemaVersion = 2` one-time v1->v2 migration).
  - `SeasonSkipPreference` (`introEnabled`, `outroEnabled`, `introSeconds`, `outroSeconds`, `SeasonSkipMode`: `.manual` / `.automatic`, `chapterDetection`), `ChapterSkipDetector`.
  - `PlaybackHealthPolicy` & `PlaybackHealthEvaluation` — bounded stall detection (monitors time progress `>= 0.1s` or buffer progress `>= 0.5s`; triggers `.recover` once before `.fail`).
  - `PlaybackDiagnosticsRedactor` — regex secret & host redaction (`token|password|passwd|pwd|authorization|api_key|x-emby-token|delivery_key` + `https?://<HOST>`).
- `Sources/DonbyCore/EmbyModels.swift` — `ServerType`, `EmbyServerConfig` (backward-compatible `keepSignedIn`, `lastLoginDate`, `tokenExpiresAt`), `ServerLineInfo` (`cleanDisplayName` normalizing CDN labels to `Cloudflare Pro CDN` / `Cloudflare CDN` / `中国大陆 CDN` and auto-stripping legacy `" · ..."` descriptions, `cleanDisplayHost`, optional speed/exit cache), `EmbyItem`, `MediaSourceInfo`.
- `Sources/DonbyCore/EmbyChapterInfo.swift` — `EmbyChapterInfo` model.
- `Sources/DonbyCore/ResolvedPlaybackResource.swift` — `ResolvedPlaybackResource` stream resolution payload.
- `Sources/DonbyCore/MediaServiceProvider.swift` — `DonbyMediaServiceProvider` / `DonbyMediaServiceRegistry` (decoupled extension seam allowing optional modules like `DonbyUHDModule` to register/unregister at runtime without coupling `DonbyCore` or `DonbyNetwork`).
- `Sources/DonbyCore/AppStateModels.swift` — `MainNavigationTab`, `ActivePlaybackSession`, `WatchRecordItem` (persists `mediaType` & `seriesId`), `LocalMediaFolder`, `IPTVChannelItem`, `AppThemeColor`, `AppAppearanceMode`.
- `Sources/DonbyCore/AppUpdatePolicies.swift` — `DonbyAppInfo` (single Swift source of truth for `version` & `fallbackVersion`), `AppReleaseInfo`, `AppVersionComparator`, `GitHubReleaseDTO`, `StaticManifestDTO` (`latest.json`).
- `Sources/DonbyCore/ServerTextParser.swift` — Bulk/paste server config importer (`ParsedServerImportResult`).
- `Sources/DonbyCore/SubtitleAutoAligner.swift`
  - `SileroVAD` — zero-dependency native Apple `Accelerate` (`vDSP_mmul`) inference engine for official Silero VAD v5/v6 `16kHz` weights (`Resources/silero_vad_16k.safetensors`, 1.24 MB, MIT; verified `< 1e-4` against official `silero_vad.jit` golden outputs).
  - `SubtitleAutoAligner` — Audio-first ground-truth alignment: (1) `alignAudioFirst`: overlap-clipped exact Pearson VAD correlation (`>= 10s` audio, `>= 65%` valid cue overlap, split-half consistency check, current-delay/zero-lag stability guard) that locks both primary and secondary tracks to audio in one click; (2) `alignDualAudioAnchored` / `alignDualSubtitles`: 2-stage coarse-to-fine (`0.25s -> 0.04s`) multi-window envelope cross-correlation + cinema FPS drift (`23.976/24/25fps`) + Silero VAD anchor selection so an audio-synced secondary track pulls a drifted primary track instead of being dragged off-sync.

## 2. Critical Invariants & Pitfalls (DO NOT BREAK)
1. **`DONBY_HOME` Isolation**: Every cache/storage path in `DonbyNetwork` and `DonbyApp` MUST route through `DonbyStoragePaths` (never hardcode `FileManager.default.urls(for: .cachesDirectory, ...)` directly), so automated tests with `DONBY_HOME=$(mktemp -d)` remain 100% isolated from user data.
2. **ASS Tag Preservation**: Any changes to `SubtitleTextTransform` must preserve `{...}` ASS formatting tags intact.
3. **Diagnostic Redaction**: Never weaken `PlaybackDiagnosticsRedactor` secret-stripping regexes, and always redact stream URLs/tokens before calling `DonbyLogger.shared.log(...)`.
4. **Zero Keychain Prompts on Ad-Hoc Builds (`v1.4.16`)**: Never store routine server credentials in macOS Login Keychain while Donby uses ad-hoc signing (`codesign -s -`), as CDHash changes trigger macOS password dialogs on every update. Keep credentials in the machine-bound AES-256-GCM `0600` vault (`EncryptedFileVaultBackend`) and preserve `vaultReadBlocked` / write-failure data-loss guards.
