## 2. Key Player UX State Machine (`PlayerView.swift`)
- **Startup Loading Pill**: Remains visible until `DKMetalVideoView.onFirstFrameRendered` sets `hasRenderedFirstFrame = true` (prevents black-screen flicker between `dk_open` and first presented frame).
- **Seek Settling Guard (`isSettlingSeek`)**: `2.5s` window after seek so timeline scrubber does not snap back to stale pre-seek PTS while decoder flushes.
- **Delayed Rebuffer Pill**: Only shows `"正在缓冲..."` after `>= 0.48s` of continuous rebuffering so brief micro-stalls do not flash UI chrome.
- **Prewarm & Next-Episode Prefetch**: `DetailView` / `PlayerView` prewarm redirect/playback info and prefetch next episode near end.

## 3. Critical Invariants & Pitfalls (DO NOT BREAK)
1. **120Hz Scroll Hygiene**: Never do synchronous disk I/O, offscreen shadows, or SwiftUI layout thrashing inside `NativeEmbyHomeView` / `NativePosterGridView` scroll paths; respect `ScrollActivityTracker.isScrolling` and `ScrollHoverGate`. Keep `HorizontalShelfScrollView` horizontal scroller hidden via `tile()` and avoid forced scroll-snapping (feels unnatural on macOS trackpad).
2. **Hit-Testing in Native Collection Views**: Preserve `InteractiveCollectionView` click/hover hit-testing (`v1.3.20` regression fix).
3. **Hero Backdrop, Fullscreen Framing & ClearLogo Hygiene (`v1.4.23`)**: In `DetailView.heroHeaderSection` and `MainCarouselView`, scale banner heights responsively for fullscreen (`DetailView`: `440...680`, Home carousel: `365...540`) and pass `alignment: .top` to `MediaArtworkView` so faces are never clipped on wide screens. Keep the upper ~46% of `DetailView`'s backdrop completely clear and vivid at rest (`minY == 0`, `blur = 0`, `.saturation(1.10).contrast(1.04)`), applying stretchy overscroll + progressive blur only during pull-down/scroll; dissolve smoothly in a single direction into `canvasCol` (`0.46 -> 1.0`). In `ClearLogoHeaderView`, never use white-halo glow on dark fallback text, and suppress duplicate text subtitle underneath a loaded movie/series ClearLogo.
4. **Card Interaction, Badge & Copy Consistency**: Clicking any poster or landscape card always enters `DetailView` (no center hover play button triggering immediate playback). Cards omit resolution badges and rating stars; downloaded badges use unified monochrome smoked-glass pill + white `checkmark` with `"已下载"` copy (never `"已离线下载"`). Sidebar places concrete servers at top above `搜索 -> 服务器 -> 文件 -> 记录 -> 下载 -> IPTV -> 设置`.
5. **Detail Preload Play-Button Binding (`v1.4.4`)**: `DetailView.effectivePlayButtonStartSeconds` binds background preloading directly to the Play button's exact start position (resume position, or automatic intro-skip landing position when starting at 0s) and re-evaluates whenever target/source/start position updates.
6. **Menu Flicker, Custom Chrome & Full-Area Single-Click Hit-Testing (`v1.4.7`, `v1.4.15`, `v1.4.22`)**: Keep `PlayerView` timers (`progressTimer`, `embySyncTimer`) on `.default` RunLoop mode (never `.common`, which fires during macOS `NSMenu` `.eventTracking`), store high-frequency mouse-move/auto-hide/hidden-HUD playback state in non-observable `PlayerAutoHideBox`, and for styled macOS `Menu` buttons (`LiquidGlassCircleMenu`, `LiquidGlassSelectorCard`, `PlayerCircleMenu`, drawer selectors) ALWAYS render visual chrome outside `Menu`'s `label:` behind a transparent `Menu` overlay using `.menuStyle(.button).buttonStyle(.plain).menuIndicator(.hidden)` with explicit `.frame` + `.contentShape(...)` (NEVER `.menuStyle(.borderlessButton)`, which collapses `SwiftUIPopupButton` hit rects to ~6×14px). Every `.buttonStyle(.plain)` control MUST declare an explicit `.contentShape(...)` matching its full visual silhouette.
7. **Zero Synchronous Disk Scans in SwiftUI `body` & Detail Navigation Preservation (`v1.4.22`)**: Never call `DonbyOfflineLibraryStorage.scanOfflineLibrary`, `DonbyTurboCacheEngine.cachedProgress`, or `NSImage(contentsOf:)` inside SwiftUI `body` (`DetailView` caches offline/Turbo snapshots asynchronously via `Task.detached`; `FilesModuleView` uses async `LocalFileThumbView`). Keep base Home/Library views mounted underneath `DetailView` in `MainWindowView`'s `ZStack` (`.opacity(hasDetail ? 0 : 1)` + `.allowsHitTesting(!hasDetail)`) so Back navigation is instant and preserves scroll/pagination.
8. **Settings Card Width & Traffic-Light Clearance (`v1.4.32`)**: Always wrap cards in `SettingsView` with `settingsCard(...)` enforcing `.frame(maxWidth: .infinity)` so narrow toggles/pickers never produce mismatched card widths; never place collapsed-sidebar buttons inside macOS's top-left `0...74pt` traffic-light zone (in `SettingsView`, right-align `[sidebar.left]` inside the 190px settings sidebar header row).
9. **Version Source of Truth**: All Swift modules read `DonbyAppInfo.version` (`Sources/DonbyCore/AppUpdatePolicies.swift`); when bumping versions, update `build_app.sh`, `DonbyAppInfo.fallbackVersion`, and `docs/agent/INDEX.md`.
10. **Log Redaction**: `AppState` `媒体流解析成功` log must keep stream URL host/query redacted.
