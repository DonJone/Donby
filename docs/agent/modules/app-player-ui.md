## 2. Key Player UX State Machine (`PlayerView.swift`)
- **Startup Loading Pill**: Remains visible until `DKMetalVideoView.onFirstFrameRendered` sets `hasRenderedFirstFrame = true` (prevents black-screen flicker between `dk_open` and first presented frame).
- **Seek Settling Guard (`isSettlingSeek`)**: `2.5s` window after seek so timeline scrubber does not snap back to stale pre-seek PTS while decoder flushes.
- **Delayed Rebuffer Pill**: Only shows `"正在缓冲..."` after `>= 0.48s` of continuous rebuffering so brief micro-stalls do not flash UI chrome.
- **Prewarm & Next-Episode Prefetch**: `DetailView` / `PlayerView` prewarm redirect/playback info and prefetch next episode near end.

## 3. Critical Invariants & Pitfalls (DO NOT BREAK)
1. **120Hz Scroll Hygiene**: Never do synchronous disk I/O, offscreen shadows, or SwiftUI layout thrashing inside `NativeEmbyHomeView` / `NativePosterGridView` scroll paths; respect `ScrollActivityTracker.isScrolling` and `ScrollHoverGate`. Keep `HorizontalShelfScrollView` horizontal scroller hidden via `tile()` and avoid forced scroll-snapping (feels unnatural on macOS trackpad).
2. **Hit-Testing in Native Collection Views**: Preserve `InteractiveCollectionView` click/hover hit-testing (`v1.3.20` regression fix).
3. **DetailView `#03` Static Top-Edge Strip, Zero Zoom/Blur, Pinned Nav & Scroll Monitor Detach (`v1.4.24–v1.4.31`)**:
   - Scale banner heights responsively (`DetailView`: `440...680`, `MainCarouselView`: `365...540`) and top-align wide artwork via `MediaArtworkView(alignment: .top)` implemented as `Color.clear.overlay(alignment: alignment) { Image.resizable().scaledToFill() }.clipped()` so faces are never cropped.
   - Never mutate `DetailView` hero height/scale or apply blur during scroll or pull-down overscroll. Place static `HeroTopEdgeBackdropView` (driven by `HeroTopEdgeSynthesizer.synthesizeWeightedStrip` matching the hero's Display P3/sRGB gamut, horizontal crop, and `.saturation(1.10).contrast(1.04)` with zero zoom and zero blur) behind `.scrollContentBackground(.hidden)`.
   - Hide DetailView vertical/horizontal scrollbars (`ScrollView(showsIndicators: false)` + `DetailScrollViewTopInsetFix` disabling `automaticallyAdjustsContentInsets` and zeroing `contentInsets.top`, `hasVerticalScroller`, and `hasHorizontalScroller` so two-finger pull-down bounces cleanly back to `y = 0` instead of hanging at `+28pt`).
   - Keep `floatingTopNavBar` pinned outside `ScrollView` in `DetailView.body`'s `ZStack(alignment: .top)`.
   - Detach `MainCarouselView`'s `TrackpadHorizontalSwipeDetector` whenever `appState.currentDetailItem != nil || appState.activePlayback != nil`, and never swallow `.began`/`.ended`/`.cancelled`/`.mayBegin` scroll-wheel lifecycle events (swallowing `.ended` freezes `DetailView` elastic bounce).
   - Dissolve hero smoothly in a single direction into `canvasCol` (`0.46 -> 1.0`); in `ClearLogoHeaderView`, never add white-halo glow on dark fallback text and suppress duplicate subtitle text underneath a loaded movie/series ClearLogo.
4. **Card Interaction, Badge & Copy Consistency**: Clicking any poster or landscape card always enters `DetailView` (no center hover play button triggering immediate playback). Cards omit resolution badges and rating stars; downloaded badges use unified monochrome smoked-glass pill + white `checkmark` with `"已下载"` copy (never `"已离线下载"`). Sidebar places concrete servers at top above `搜索 -> 服务器 -> 文件 -> 记录 -> 下载 -> IPTV -> 设置`.
5. **Detail Preload Play-Button Binding (`v1.4.4`)**: `DetailView.effectivePlayButtonStartSeconds` binds background preloading directly to the Play button's exact start position (resume position, or automatic intro-skip landing position when starting at 0s) and re-evaluates whenever target/source/start position updates.
6. **Menu Flicker, Custom Chrome & Full-Area Single-Click Hit-Testing (`v1.4.7`, `v1.4.15`, `v1.4.22`)**: Keep `PlayerView` timers (`progressTimer`, `embySyncTimer`) on `.default` RunLoop mode (never `.common`, which fires during macOS `NSMenu` `.eventTracking`), store high-frequency mouse-move/auto-hide/hidden-HUD playback state in non-observable `PlayerAutoHideBox`, and for styled macOS `Menu` buttons (`LiquidGlassCircleMenu`, `LiquidGlassSelectorCard`, `PlayerCircleMenu`, drawer selectors) ALWAYS render visual chrome outside `Menu`'s `label:` behind a transparent `Menu` overlay using `.menuStyle(.button).buttonStyle(.plain).menuIndicator(.hidden)` with explicit `.frame` + `.contentShape(...)` (NEVER `.menuStyle(.borderlessButton)`, which collapses `SwiftUIPopupButton` hit rects to ~6×14px). Every `.buttonStyle(.plain)` control MUST declare an explicit `.contentShape(...)` matching its full visual silhouette.
7. **Zero Synchronous Disk Scans in SwiftUI `body` & Detail Navigation Preservation (`v1.4.22`)**: Never call `DonbyOfflineLibraryStorage.scanOfflineLibrary`, `DonbyTurboCacheEngine.cachedProgress`, or `NSImage(contentsOf:)` inside SwiftUI `body` (`DetailView` caches offline/Turbo snapshots asynchronously via `Task.detached`; `FilesModuleView` uses async `LocalFileThumbView`). Keep base Home/Library views mounted underneath `DetailView` in `MainWindowView`'s `ZStack` (`.opacity(hasDetail ? 0 : 1)` + `.allowsHitTesting(!hasDetail)`) so Back navigation is instant and preserves scroll/pagination.
8. **Settings Card Width & Traffic-Light Clearance (`v1.4.32`)**: Always wrap cards in `SettingsView` with `settingsCard(...)` enforcing `.frame(maxWidth: .infinity)` so narrow toggles/pickers never produce mismatched card widths; never place collapsed-sidebar buttons inside macOS's top-left `0...74pt` traffic-light zone (in `SettingsView`, right-align `[sidebar.left]` inside the 190px settings sidebar header row).
9. **Always-Dark Cinema Glass Hygiene (`v1.4.37`)**: Never use `.fill(.ultraThinMaterial)` inside always-dark `PlayerView` or dark Liquid Glass modifiers (`NSVisualEffectView` inherits `NSWindow.appearance` `.aqua` in Light Mode regardless of child `.environment(\.colorScheme, .dark)`, bleeding white frosted glass behind white text). Switch root window `preferredColorScheme` to `.dark` during active playback, use deterministic dark cinema glass fills, and bind `LogViewerSheet` directly to `appState.isLightMode`.
10. **Zero Native macOS System-Blue Controls (`v1.4.35–v1.4.36`)**: Never use native `.toggleStyle(.checkbox)`, `.toggleStyle(.switch)`, `.pickerStyle(.segmented)`, `.pickerStyle(.radioGroup)`, `.buttonStyle(.borderedProminent)`, `.textFieldStyle(.roundedBorder)`, bare `Slider`, `NSColor.controlAccentColor`, or raw `.blue`; always use `DonbyCheckboxToggleStyle`, `DonbySwitchToggleStyle`, `DonbySegmentedControl`, `DonbySlider`, `.donbyFlatTextField(isLight:)`, `.focusEffectDisabled()`, and root `.tint(appState.accentColor)` on `MainWindowView` and sheets.
11. **Sidebar Protection, Toolbar Clamping & Atomic Sheet State (`v1.4.34–v1.4.35`)**: Keep `MainWindowView` right pane clamped with `.frame(minWidth: 0, maxWidth: .infinity, maxHeight: .infinity).clipped()`, keep `.focusable(false)` on sidebar collapse/expand buttons and `.layoutPriority(1)` on `appSidebarView`, never apply `.fixedSize(horizontal: true, vertical: false)` to variable-length API pills inside `embyTopToolbar`, and present server configuration via atomic `.sheet(item: $appState.serverEditorRequest)`.
12. **Professional CDN Naming, Zero AI-Slop Copy & UHD Module Isolation (`v1.4.34–v1.4.37`)**: Display full professional CDN labels (`Cloudflare Pro CDN`, `Cloudflare CDN`, `中国大陆 CDN`), omit fake CDN latency (`ms`) and exit geography from route rows, avoid cheap colored status badges or colloquial labels (`最快`, `切换最快`, `自动续订`, pastel red buttons, `测当前`, `测全部`, `清零`, `复制码`), and guard every optional UHD UI touchpoint with `#if canImport(DonbyUHDModule)` + `UHDModuleManager.shared.isActive(for:)`.
13. **WindowServer GPU Danmu Engine (`v1.4.36–v1.4.37`)**: Gate `loadUHDDanmuIfEnabled()` until after `hasRenderedFirstFrame`, pass comments via reference-type `UHDDanmuTrack`, and render in `DanmuSpriteHostView` using a pre-allocated pool of 36 `CATextLayer`s animated by WindowServer GPU `CABasicAnimation(keyPath: "position.x")` with a lightweight 5Hz (`0.20s`) spawn timer (zero main-thread `CGContext` allocations or 60fps position polling).
14. **Version Source of Truth & Log Redaction**: All Swift modules read `DonbyAppInfo.version` (`Sources/DonbyCore/AppUpdatePolicies.swift`); when bumping versions, update all 5 version locations per `AGENTS.md` Section 2. `AppState` `媒体流解析成功` log must keep stream URL host/query redacted.
