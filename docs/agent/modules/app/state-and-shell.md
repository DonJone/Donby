- `Sources/DonbyApp/DonbyApp.swift` — `AppDelegate` (auto-detaches residual mounted DMGs on launch, single-instance hygiene, `donby://` URL scheme dispatch), `DonbyApp` root scene (binds root window `preferredColorScheme` to `appState.colorScheme` to avoid light/dark flashes).
- `Sources/DonbyApp/MainWindowView.swift` — root navigation shell (`appSidebarView` with concrete servers above `搜索 -> 服务器 -> 文件 -> 记录 -> 下载 -> IPTV -> 设置`), mounted-underneath Home/Library + `DetailView` `ZStack` (keeps `EmbyMainView()` mounted across tab switches when `activeServer != nil` for zero-redraw tab return, and kept mounted underneath `PlayerView` during playback with `.preferredColorScheme(.dark)` scoped to `PlayerView`), atomic `.sheet(item: $appState.serverEditorRequest)`, `ServerLinePickSheet`, `AppUpdatePromptSheet`, and `DonbyToastOverlayView` isolated toast host.
- `Sources/DonbyApp/LogViewerSheet.swift` — redacted runtime log viewer sheet; binds directly to `appState.isLightMode` and uses debounced `cachedFilteredEntries` (150ms search debounce).
- `Sources/DonbyApp/Extensions/DonbyAppExtension.swift` — `DonbyAppUIExtensionPlugin` (including `isAnimeModeActive(for:)`, `resolveImdbIds(for:server:maxCount:)`, `metadataCacheSizeBytes()`, and `clearMetadataCacheAsync()`), `DonbyPlayerCompanion`, `DonbyPlayerCompanionBox`, `DonbyPlayerHostDriver`, `PlayerCompanionSheetsModifier`, `DonbyExtensionSettingsCard`, `PlayerDrawerGlassCard`, `PlayerDrawerRowBackground`, and the single `#if canImport(DonbyUHDModule) && !DONBY_PURE_BUILD` bootstrap in `DonbyAppExtensionCenter`.
- `Sources/DonbyApp/AppState.swift` — `@MainActor` core: `ServerEditorRequest`, stored `@Published` / `@AppStorage` properties (including `cachedHomeShelves`, `homeRevision`, `hideWatchedInLatest` triggering `loadActiveServerHome(syncDomains: false, forceRefresh: true)`), plain `let` scoped store handles (`toastStore`, `downloadStatusStore`, `searchStore`, `ratingsStore`, `watchHistoryStore`) with non-`@Published` computed forwarding properties (`toastMessage`, `downloadStatusIndex`, `globalSearchQuery`, `globalSearchRemoteResults`, `multiPlatformRatingsByItemId`, `watchHistory`), `cardAppearance` / `cardAppearance(downloadStatusIndex:)` and theme/palette helpers, `init()` (with async `Task.detached` hydration and delayed `Task.detached` `enforceDiskBudget`), `prepareForTermination()`, disk persistence (`load*FromDisk` / `save*ToDisk` with debounced off-MainActor `saveServersToDisk`).
- `Sources/DonbyApp/AppState+ScopedStores.swift` — `@MainActor` scoped `ObservableObject` stores (`DonbyDownloadStatusStore`, `DonbySearchStore`, `DonbyRatingsStore`, `DonbyWatchHistoryStore`) isolating high-frequency state from root `AppState`, batched home-shelf update helpers (`performBatchedHomeShelfUpdate`, `performWithoutHomeShelfRefresh`, `mergeRatingsBatch`), and top-level navigation (`openServer` with 120s SWR `isSnapshotFresh` check, `applyHomeSnapshot` preserving non-empty `snap.carouselItems` and prewarming hero backdrop, `selectSidebarModule`).
- `Sources/DonbyApp/AppState+PerformanceStores.swift` — `DonbyToastStore`, off-MainActor `Task.detached` `refreshCachedHomeShelvesIfNeeded` / `computeHomeShelfDrafts`, `scheduleHomeCurationAndRatingsEnrichment`, async initial disk hydration (`scheduleAsyncDiskHydration` preloading all server snapshots + active hero backdrop), `ServerHomeModeCacheBox` (`lastSyncedAtByCompositeKey`), and `ServerHomeCacheStore` SWR (`swrFreshnessTTL`, `markSyncedNow`, `isSnapshotFresh`) + unified disk budget/cleanup (`diskCacheSizeBytesAsync`, `pruneIfNeededAsync`, `clearModeCache`, `clearAllAsync`).
- `Sources/DonbyApp/AppState+HomeAndLibrary.swift` — home shelf loading (`loadActiveServerHome(syncDomains:forceRefresh:)` with atomic background refresh when cached home is already displayed, fetching `CriticRating,CommunityRating` top Movie/Series pools), canonical `finalizeHomeContent` (batched shelf updates + delegated off-MainActor `HomeHeroCurator.selectHeroItems` curation and multi-platform rating enrichment), `ensureMultiPlatformRating` single-item hero hydrator, `ServerHomeCacheStore` persistence, library browsing state, search history/query helpers, local folder / IPTV / recent-media mutations.
