# App Sub-Map: Entry, Window Shell, AppState & Extension Seam

> Parent: [app/INDEX.md](INDEX.md). Covers 10 files: `DonbyApp.swift`, `MainWindowView.swift`, `LogViewerSheet.swift`, `Extensions/DonbyAppExtension.swift`, and `AppState.swift` + 5 extensions.

## 1. File Inventory & Responsibilities
- `Sources/DonbyApp/DonbyApp.swift` — `AppDelegate` (auto-detaches residual mounted DMGs on launch, single-instance hygiene, `donby://` URL scheme dispatch), `DonbyApp` root scene (switches root window `preferredColorScheme` to `.dark` during active playback).
- `Sources/DonbyApp/MainWindowView.swift` — root navigation shell (`appSidebarView` with concrete servers above `搜索 -> 服务器 -> 文件 -> 记录 -> 下载 -> IPTV -> 设置`), mounted-underneath Home/Library + `DetailView` `ZStack`, atomic `.sheet(item: $appState.serverEditorRequest)`, `ServerLinePickSheet`, `AppUpdatePromptSheet`.
- `Sources/DonbyApp/LogViewerSheet.swift` — redacted runtime log viewer sheet; binds directly to `appState.isLightMode`.
- `Sources/DonbyApp/Extensions/DonbyAppExtension.swift` — `DonbyAppUIExtensionPlugin` (including `isAnimeModeActive(for:)` and `resolveImdbIds(for:server:maxCount:)`), `DonbyPlayerCompanion`, `DonbyPlayerCompanionBox`, `DonbyPlayerHostDriver`, `PlayerCompanionSheetsModifier`, `DonbyExtensionSettingsCard`, `PlayerDrawerGlassCard`, `PlayerDrawerRowBackground`, and the single `#if canImport(DonbyUHDModule) && !DONBY_PURE_BUILD` bootstrap in `DonbyAppExtensionCenter`.
- `Sources/DonbyApp/AppState.swift` — `@MainActor` core: `ServerEditorRequest`, all `@Published` / `@AppStorage` stored properties, theme/palette computed helpers, `init()`, `prepareForTermination()`, disk persistence (`load*FromDisk` / `save*ToDisk`), `showToast`, top-level navigation (`openServer`, `selectSidebarModule`).
- `Sources/DonbyApp/AppState+HomeAndLibrary.swift` — home shelf loading (fetches `CriticRating,CommunityRating` top Movie/Series pools), canonical `finalizeHomeContent` (routes `carouselItems` strictly through `HomeHeroCurator.selectHeroItems` with server/hall anime context, triggers `PlaybackIntentCoordinator.warmServerOnConnectOrLaunch` + top-2 `继续观看` `warmShelfCandidates`, seeds cached ratings into `multiPlatformRatingsByItemId`, and runs async multi-platform rating enrichment), `ensureMultiPlatformRating` single-item hero hydrator, `ServerHomeCacheStore` integration, library browsing state, search history/query helpers, local folder / IPTV / recent-media mutations.
- `Sources/DonbyApp/AppState+PlaybackLifecycle.swift` — playback launch orchestration (`ActivePlaybackSession`, `0ms` synchronous `PlaybackIntentCoordinator.cachedResolvedResource` fast-table hit before remote resolution), stream resolution, `detailFocusedEpisodeMemory` sync, pre-playback preparation.
- `Sources/DonbyApp/AppState+WatchRecords.swift` — watch history persistence (max 300, deduplicated, preserves `mediaType` & `seriesId`), `resolveSeriesName` via `DonbyMediaServiceRegistry`, `makeWatchRecordStubItem` for resume/replay.
- `Sources/DonbyApp/AppState+DownloadsAndCache.swift` — download queue helpers (`effectiveConnectionBudget`, `effectiveDownloadConnectionBudget` lifting default 4 to 6 on unlimited servers while respecting 1..3 user caps and positive server limits, `.withInheritedArtworkFallback(...)` for UHD episode downloads), auto-archive finished cleanup, Turbo cache budget enforcement.
- `Sources/DonbyApp/AppState+ServersAndLines.swift` — server CRUD, clipboard import, `connectAndSaveServer`, `isUsingUHDExtension`, `reloadAfterModuleToggle`, `syncExtDomains`, `switchLineImmediate` (invalidates playback/route caches and preconnects 4 lanes via `PlaybackIntentCoordinator.warmServerOnConnectOrLaunch`), `pingAllLines`, `handleIncomingURL(_:)`.

## 2. Critical Invariants (DO NOT BREAK)
1. **Sidebar & Right-Pane Clamping (`v1.4.34–v1.4.35`)**: Keep `MainWindowView` right pane clamped with `.frame(minWidth: 0, maxWidth: .infinity, maxHeight: .infinity).clipped()`, `.focusable(false)` on sidebar collapse/expand buttons, `.layoutPriority(1)` on `appSidebarView`, and atomic `.sheet(item: $appState.serverEditorRequest)`.
2. **Detail Navigation Preservation (`v1.4.22`)**: Keep base Home/Library views mounted underneath `DetailView` in `MainWindowView`'s `ZStack` (`.opacity(hasDetail ? 0 : 1)` + `.allowsHitTesting(!hasDetail)`) so Back navigation is instant and preserves scroll/pagination.
3. **Log Redaction**: `AppState` `媒体流解析成功` logs must keep stream URL host/query redacted.
4. **Disk Persistence Encapsulation**: Keep `load*FromDisk`/`save*ToDisk` inside `AppState.swift` so `isLoadingFromDisk` and storage key constants remain `private`.
