# Module Map: Build, Packaging & Release Pipeline

> Last synced: `v2.1.1`. Load this doc for compiling Swift/Rust/C11, `DONBY_PURE=1` pure builds, bundling dylibs, signing `/Applications/Donby.app`, DMG/ZIP packaging, channel-aware local GitHub Releases, agent doc-sync gates, and CI.

## 1. File Inventory
- `Package.swift` — SwiftPM manifest compiling pure-C11 `DonbyKernelC` (`dk_ffi_shim*.c`), linking `build_kernel/libdonby_kernel.a` (`KernelRust`) into `DonbyKernelC` and `DonbyNetwork`, optional `DonbyUHDModule` (omitted alongside `Modules/UHD` when `DONBY_PURE=1` sets `-DDONBY_PURE_BUILD`), and `DonbyCoreTests`.
- `build_kernel.sh` + `KernelRust/` — Builds zero-dependency Rust `staticlib` (`KernelRust/Cargo.toml`) into `build_kernel/libdonby_kernel.a` (only overwrites output when bytes change so SwiftPM skips redundant relinks).
- `scripts/dev.sh` — Fast local CLI wrapper (`build` / `test` / `app` / `release`) that auto-wires `core.hooksPath=.githooks`, runs `scripts/check_agent_docs.py` on `test`, runs `./build_kernel.sh` (+ `cargo test` on `test`), auto-selects valid CLT SDK, uses `--build-system native` (avoiding Swift 6.4 `swiftbuild` 54s no-op cache-invalidation bug), and passes CLT `Testing.framework` search paths + isolated `DONBY_HOME`.
- `build_app.sh` — Incremental Release build: uses `--build-system native` + multi-core incremental `-O` (`-no-whole-module-optimization -incremental`, opt-in `DONBY_WMO=1`), skips up-to-date `AppIcon.icns`, bundles `Resources/silero_vad_16k.safetensors` into `Contents/Resources/`, preserves `/Applications/Donby.app` inode and cached `Contents/Frameworks/` dylibs, signs app bundle (`codesign --force --sign -`), and verifies `--deep --strict`.
- `scripts/bundle_dylibs.py` — Batches `install_name_tool` flags per binary, reuses valid cached `@rpath` dylibs in `Contents/Frameworks/` across incremental installs, prunes stale dylibs, signs only modified dylibs in parallel, and verifies zero external Homebrew refs.
- `scripts/generate_icon.swift` — Programmatically renders the sculptural obsidian D monogram `AppIcon.icns`.
- `scripts/package_dmg.sh` — Builds `dist/Donby-<ver>-macOS-<arch>.dmg`, `.app.zip`, `latest.json`, and `SHA256SUMS.txt`, and optionally syncs `/Applications/Donby.app/Contents` in-place (`SYNC_INSTALLED_APP=1`).
- `scripts/release_local.sh` — Local-first release: runs `scripts/check_agent_docs.py`, packages artifacts, syncs `/Applications/Donby.app` in-place (disable via `--no-install`), pushes branch, creates/updates GitHub Release via `gh`, syncs tag.
- `scripts/check_agent_docs.py` — Zero-dependency mechanical gate enforcing the `<= 800L` source ratchet (`LEGACY_LINE_CAPS`), `1:1` module-doc inventory bijection, link/version/emoji hygiene, and staged domain co-change checks.
- `.githooks/pre-commit` & `.githooks/commit-msg` — Tracked Git hooks invoking `scripts/check_agent_docs.py --staged` and `--commit-msg`.
- `.github/workflows/build-dmg.yml` — GitHub Actions CI triggered on tag push `v*` (runs `scripts/check_agent_docs.py`, skips DMG build if `[local-release]` workflow already published or builds DMG/ZIP in CI).

## 2. macOS CLT SDK & Swift 6.4 Build System Workaround (IMPORTANT)
- On macOS with CommandLineTools (`xcode-select -p` == `/Library/Developer/CommandLineTools`), the default SDK may reference `SwiftUIMacros` without `libSwiftUIMacros.dylib`, and Swift 6.4's default `swiftbuild` engine invalidates explicit SDK module caches on every run (~54s no-op).
- **Always use**: `./scripts/dev.sh build` / `./scripts/dev.sh test` (or pass `--build-system native --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk`). `build_app.sh` feature-detects `--build-system` automatically so older Swift CI runners remain compatible.

## 3. Critical Invariants & Pitfalls (DO NOT BREAK)
1. **Preserve `/Applications/Donby.app` Inode**: `build_app.sh` and `AppUpdateManager` replace `/Applications/Donby.app/Contents` in-place rather than `rm -rf /Applications/Donby.app` so macOS Dock does not lose the pinned app reference or spawn duplicate Dock icons (`v1.3.33`).
2. **No Stray `./Donby.app` in Workspace**: `build_app.sh` unregisters (`lsregister -u`) and removes `./Donby.app` to prevent LaunchServices duplicate bundle registration (`v1.3.17`).
3. **Version Bump & Mandatory Release Checklist**: Every code commit MUST bump `vX.Y.Z` atomically in all 5 version locations (`build_app.sh` `APP_VERSION`, `scripts/package_dmg.sh` `VERSION` fallback literal, `Sources/DonbyCore/AppUpdatePolicies.swift` `DonbyAppInfo.fallbackVersion`, `Tests/DonbyCoreTests/DonbyCoreTests.swift` `appVersionFallbackNonEmpty` assertion, and `docs/agent/INDEX.md` `Current Version`) and publish a GitHub Release via `./scripts/release_local.sh X.Y.Z` (defaults to `--prerelease`; pass `--stable` ONLY when user explicitly requests a Stable release). Pure `docs:` commits do not bump versions or publish releases.
4. **Release Channels (`Stable` vs `Pre-release`)**: `AppUpdateChannel` (`DonbyCore/AppUpdatePolicies.swift`) + `AppUpdateManager.updateChannel` let users switch between `正式版 (Stable)` (`/releases/latest` + `latest.json`) and `预览版 (Pre-release)` (`/releases?per_page=15` including pre-releases).
5. **Tiered Verification Rule**: Never run `./build_app.sh`, DMG packaging, or `./scripts/release_local.sh` during intermediate edits; use L1 `./scripts/dev.sh build` and L2 `./scripts/dev.sh test` until milestone delivery or explicit release.
6. **Mechanical Doc-Sync & Source-Size Gate**: Never bypass `.githooks/` or raise `LEGACY_LINE_CAPS` in `scripts/check_agent_docs.py`; keep every new or refactored source file `<= 800L` and listed `1:1` in its module map.
